Spaced Repetition (Kanban)

📚 How the Leitner Method Works (click to expand)

The Leitner method is a spaced repetition system that organizes flashcards into boxes based on how well you remember them. Every time you answer a card correctly, it moves to the next box, meaning it will be reviewed less frequently. If you answer incorrectly, the card returns to Box 1, where it is reviewed more often.

This approach helps you spend more time on concepts you find difficult while gradually increasing the interval between reviews for concepts you already know well.

Review Schedule

  • Box 1: Review every day, a few hours after finishing a study session.
  • Box 2: Review every day before starting to study.
  • Box 3a: Review every Wednesday, after Box 2.
  • Box 3b: Review every Saturday, after Box 2.
  • Box 4: Review every Sunday.
  • Box 5: Review at the end of each month or during the week before an exam.

Rule: Correct answers move a card to the next box, while incorrect answers return it to Box 1. Cards in Box 2 move to Box 3b from Monday to Thursday and to Box 3a from Friday to Sunday.
